# Day 18 - Region Performance Analysis

## Objective
To compare sales and profit across different regions using the Superstore dataset.

## Dataset
Sample Superstore

## Tools Used
- Microsoft Excel
- Power BI

## Analysis Performed
- Region-wise sales analysis
- Region-wise profit analysis
- Profit margin calculation
- Sales ranking
- Profit ranking
- Sales by Region visualization
- Profit by Region visualization

## Key Findings
- West recorded the highest sales and profit.
- South recorded the lowest sales.
- Central recorded the lowest profit.
- West ranked first in both sales and profit.
- East ranked second in both sales and profit.
- West had the highest profit margin, while Central had the lowest.

## Conclusion
The analysis provides a comparison of regional sales and profitability and highlights differences in regional performance.
